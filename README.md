## What I Do

I build practical AI systems end to end in Python, from data analysis and model experimentation to applications people can actually use.

| Focus | What it looks like |
| :-- | :-- |
| **Python Development** | Backend services, data pipelines, and ML tooling written in Python |
| **LLM Applications** | Generative AI workflows and chatbots built around real use cases |
| **Computer Vision** | Detection and video-processing pipelines with OpenCV and YOLO |
| **Data Science** | EDA, feature engineering, and model evaluation with the Python data stack |
| **Full-Stack Development** | APIs and interfaces that put models into users' hands |
